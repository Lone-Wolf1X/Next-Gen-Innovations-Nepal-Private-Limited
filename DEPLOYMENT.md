## 🚀 Enable GitHub Pages (Free Hosting!)

Follow these steps to make your website live:

1. **Go to your repository**:
   https://github.com/Lone-Wolf1X/Next-Gen-Innovations-Nepal-Private-Limited

2. **Click on "Settings"** tab (top right)

3. **Click "Pages"** in the left sidebar

4. **Under "Source"**:
   - Branch: Select `main`
   - Folder: Select `/ (root)`
   - Click **Save**

5. **Wait 1-2 minutes** for deployment

6. **Your website will be live at**:
   ```
   https://lone-wolf1x.github.io/Next-Gen-Innovations-Nepal-Private-Limited/
   ```
