## 🚀 Quick Start

### Local Development

1. Clone the repository:
```bash
git clone https://github.com/YOUR_USERNAME/next-gen-innovations.git
cd next-gen-innovations
```

2. Serve the files locally:
```bash
npx serve . -p 3000
```

3. Open in browser:
```
http://localhost:3000
```

### Alternative: Python Server
```bash
python -m http.server 3000
```
